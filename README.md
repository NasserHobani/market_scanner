# ماسح الأسواق — المرحلة 0

محرك مسح مستقل تماماً عن أي واجهة ويب. يجلب الشموع، يحسب منطق تسجيل VDM، ويخرج قائمة مرتّبة.

## التشغيل

### طرق التشغيل الصحيحة

```bash
python main.py --market crypto --html      # يعمل بالمسار الكامل أيضاً
python -m scanner.run --market crypto      # مكافئ
python backtest.py --market crypto --split
```

على ويندوز: انقر `start.bat` — يفتح قائمة اختيارات.

⚠️ **لا تضع نصاً عربياً داخل ملفات `.bat`.** cmd يقرأ الملف الدفعي بايتاً
بايتاً ويتتبّع موضعه فيه؛ تغيير صفحة الترميز في المنتصف يزيح المواضع فيستأنف
من نصف كلمة وينفّذ شظايا مثل `anage.py` و`ython`. كل ملفات `.bat` هنا
إنجليزية خالصة، والقائمة العربية في `start.py` لأن بايثون يقرأ UTF-8 سليماً.

⚠️ **لا تشغّل `scanner/run.py` بمساره** — بايثون لا يتعرّف على الحزمة فتنكسر
الاستيرادات النسبية. الملف يعطي رسالة واضحة إن فعلت.

⚠️ إن «أصلح» محرّرك الاستيرادات تلقائياً (PyCharm يفعل ذلك) وحوّل
`from . import storage` إلى `import storage` — أعدها كما كانت. الاستيراد
النسبي مقصود.

```bash
cd market-scanner
pip install pandas numpy pyyaml
pip install pyarrow          # اختياري: تخزين أسرع (بدونه يستخدم CSV)

python -m scanner.run --market crypto                 # كل أزواج USDT
python -m scanner.run --market crypto --top 100       # أعلى 100 بحجم التداول
python -m scanner.run --market crypto --universe list # العشرة في الإعدادات فقط
python -m scanner.run --market crypto --timeframe 1d --no-cache
```

## اختيار المحوّل

| القيمة في `adapter:` | الوصف |
|---|---|
| `binance` (افتراضي) | مدمج، مكتبة قياسية فقط، مع تحويل تلقائي بين المضيفين |
| `binance_lib` | يعتمد `pip install binance-python` |

المحوّل الثاني مكتوب دفاعياً: يستنتج أسماء حقول الشمعة بدل افتراضها، ويحوّل
`Decimal` إلى `float`. لم يُختبر على اتصال حقيقي — انظر ملاحظة الاعتمادية أدناه.

## الاتصال ببينانس

المضيف الافتراضي `data-api.binance.vision` — نقطة البيانات العامة الرسمية من Binance:
للقراءة فقط، بلا مفتاح، ولا يتأثر بالحجب الجغرافي الذي يطال `api.binance.com`
في بعض الشبكات. عند فشله يُجرَّب المضيف الرئيسي تلقائياً.

قائمة الأزواج تُبنى ديناميكياً من `ticker/24hr`، مرتّبة بحجم التداول، وتُستبعد منها:

- ما حجمه أقل من `min_quote_volume` (20 مليون دولار افتراضياً)
- رموز الرافعة المالية — بمطابقة **اللاحقة** لا الجزء: `BTCUP` نعم، `JUP` لا
- المستقرة والورقية: `USDC` `FDUSD` `RLUSD` `EUR` `TRY` ...
- الذهب المرمّز: `PAXG` `XAUT` — يتحرك مع الذهب لا مع السوق
- الأسهم المرمّزة (لاحقة B): `SPCXB` `SNDKB` — لها ساعات وفجوات مختلفة

لمعرفة سبب استبعاد أي رمز:

```bash
python main.py --market crypto --diagnose
```

يطبع مسار التصفية كاملاً وأعلى الرموز المرفوضة بسبب الحجم — إن وجدت عملات
معروفة بينها، فحد `min_quote_volume` مرتفع على سوقك.

المخرجات: جدول في الطرفية، وملف في `reports/`، ونسخة أرشيفية في `data/archive/`.

## معيار قبول المرحلة 0

الهدف ليس تطابق الأرقام على الكسور العشرية — بل **تطابق الاتجاه**.

1. شغّل الماسح على الأزواج العشرة.
2. افتح كل زوج على TradingView بنفس الفريم (الروابط جاهزة في عمود `chart`).
3. قارن إشارة كل مكوّن: `c_obv`، `c_rsi`، `c_trend`... مع صفوف الجدول في المؤشر.

**النجاح: تطابق 9 من 10 أزواج في اتجاه المكوّنات.**

مصادر الاختلاف الطبيعية: اختلاف عدد الشموع التاريخية المحمّلة، واختلاف توقيت إغلاق الشمعة الأخيرة.

## البنية

```
scanner/
  adapters/     ← binance.py  (مخرَج OHLCV موحّد)
  indicators/   ← pine.py: دوال مطابقة لـ Pine · volume.py: مؤشرات الفوليوم
  scoring/      ← engine.py: الأوزان والدرجة والقرار
  storage.py    ← تخزين تراكمي + أرشفة
  report.py     ← جدول الطرفية + CSV + روابط TradingView
  run.py        ← نقطة الدخول
config/
  crypto.yaml   ← إعدادات هذا السوق وحده
```

**قاعدة معمارية:** `adapters` هي الطبقة الوحيدة التي تعرف مصدر البيانات. إضافة السوق الأمريكي أو السعودي لاحقاً = ملف واحد هنا، بلا مساس بالمحرك.

## لماذا مؤشرات مكتوبة يدوياً

Pine يستخدم تنعيم RMA في `ta.rsi` و`ta.atr`، ويهيّئ `ta.ema` بمتوسط بسيط لأول قيمة، و`ta.vwap` يعيد التصفير مع كل جلسة. المكتبات الجاهزة تخالف هذه التفاصيل فتعطي أرقاماً مختلفة عن شارتك. `scanner/indicators/pine.py` يطابقها عمداً.

## ما يعمل الآن

عشرة مكوّنات: OBV · VWAP · CMF · MFI · A/D · اندفاع الفوليوم · OBV MACD · RSI · فلتر الاتجاه · الدلتا.

## ملاحظة على اعتمادية binance-python

قبل جعلها المصدر الافتراضي، هذه وقائع تخص الحزمة كما هي اليوم:

- آخر إصدار: **0.2.9 في 16 فبراير 2025**
- المستودع: **0 نجمة، 0 تفريعة، 29 إيداعاً**، وREADME يقول «🚧 قيد الإنشاء»
- مشرف واحد
- غير متزامنة (async) بينما المحرك متزامن — يُغلَّف كل نداء بـ `asyncio.run`
- المضيف البديل `data-api.binance.vision` لا يبدو قابلاً للضبط فيها، وهذا مهم
  لأن `api.binance.com` محجوب على بعض الشبكات

المشروع لا يعتمد عليها افتراضياً لهذا السبب: نقطة البيانات هي أساس كل شيء،
وتعطّلها يعطّل المشروع كله. لتفعيلها غيّر `adapter: binance_lib` وسطر واحد يعيدك.

بدائل أنضج إن أردت مكتبة: `ccxt` (توحّد عشرات المنصات)، `python-binance`،
أو `binance-connector` الرسمية.
